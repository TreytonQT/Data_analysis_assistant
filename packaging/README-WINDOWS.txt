销售数据分析助手 Windows 便携版

1. 将压缩包完整解压到一个固定目录，不要直接在压缩包内运行。
2. 双击 DataAnalysisAssistant.exe。
3. 程序就绪后会自动打开浏览器，地址为 http://127.0.0.1:8000。
4. 使用期间请保留启动窗口；关闭窗口即停止程序。

数据说明
- 发布包不包含任何业务数据、上传文件、SQLite 数据库或缓存。
- 首次运行会在程序旁自动创建 data 目录和空数据库。
- configs 目录包含程序运行所需的默认业务配置，可在配置中心修改。
- 迁移电脑或升级前，请备份旧程序目录中的 data 和 configs 目录。
- data/cache 是可重建缓存；应用停止后可删除，不需要备份。

安全说明
- 服务只监听本机 127.0.0.1:8000，不向局域网开放。
- 若提示 8000 端口被占用，请先关闭已运行的助手或其他占用该端口的程序。
